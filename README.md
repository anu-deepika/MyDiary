# MyDiary

A web-based diary application built using Spring MVC, Hibernate, and MySQL.

## Tech Stack

- Java
- Spring MVC
- Hibernate
- MySQL
- Maven
- Apache Tomcat
- JSP
- GitHub Actions

## Features

- User registration/login
- Create diary entries
- View diary entries
- Edit diary entries
- Delete diary entries
- Persistent storage using MySQL
